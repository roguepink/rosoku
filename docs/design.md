# 一灯 — 設計のまとめ(2026-10-22 専門家4人の相談から)

## だれのためのアプリか(市場調査)
- ろうそくアプリは多いが、ほとんどが「広告まみれ」か「機能の詰めこみすぎ」。レビューの不満の一番は広告。
- 使う理由: 眠る前・不安なとき / 瞑想(ろうそくを見つめる「トラタカ」)/ 祈り・追悼(お盆・命日・震災の日)/ 火を使えない人(子ども・ペット・賃貸・病院・介護施設)/ 電気を消して過ごす夜(「100万人のキャンドルナイト」)。
- ねらう場所: **「電気を消して、一本だけ」** — 毎晩の小さなキャンドルナイト。広告なし・数字なし・最後は暗く。ノブさんの曲がいちばん生きる。
  和ろうそくや「お線香一本ぶん」のタイマーで、祈りの使い方も自然に入る。

## なぜ この見た目か(デザイナー)
- 3案(闇の間 / 土壁と漆 / 夜の窓)から「土壁と漆」。炎を大きく・明るくすると照らされる壁の範囲も変わり、調整すること自体に意味が出る。映り込みで本物らしさが増す。
  日本の「陰」の美しさは、海外の同じジャンルにない個性。
- 避けること: 白い文字・青白い光・すりガラス・ネオン、禅アプリのお決まり(石・竹・蓮・鈴の音)、大きな数字のカウントダウン、通知、広告、連続◯日。

## 炎を本物らしくする(ろうそく・癒しの専門家)
- 炎の色の層: 青い根元(下の1割ほど)/ 芯のまわりの暗いところ / 明るい部分(いちばん明るいのは高さ4〜5割)/ だいだいの先。
- 揺れは「くり返し」に見せない: ゆっくり(0.05〜0.5Hz)・中くらい・ちらつき(8〜14Hz)を重ね、周期が割り切れないようにし、ときどき「ふっと来る風」を入れる。先端は根元より少し遅れて動く。
- 和ろうそくは炎が大きく、ゆっくり「息をする」ようにのび縮みする。これがほかのアプリにない個性。
- 光は 1850K くらいのだいだい。画面の平均の明るさは低く。夜は青い光を避ける。
- 「1/fゆらぎで癒される」は科学的な裏づけは弱い。ただ「くり返しでない自然な動きは疲れにくい」という作りの方針としては使える。

## 使いやすさ(UI/UX)
- ふだんは何も出さない。ふれると出る。最初のタッチでは何も変えない。長押し・2本指は使わない(テーブルに置いたまま触っても安全)。
- 調整は段階で選ぶ(すべり棒は音の大きさだけ)。文字は必ず添える(アイコンだけにしない)。
- iPhone はふれる前に音を出せない → 灯すタッチで音楽も始める。音は0から5秒かけて大きく。
- 画面をつけっぱなしにする(Wake Lock)。戻ってきたらかけなおす。

## 音楽
- 初めの音の大きさ 40%。始めは5秒かけて大きく、止めるときは1.5秒で小さく。
- 曲の終わり8秒を自動で小さくし、3秒しずかにしてから次へ(Suno の曲は終わりが急なことが多い)。
- 「順番に」/「ばらばら(同じ曲が続かない)」。最後まで行ったら はじめから。
